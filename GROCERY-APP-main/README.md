# ANNAI STORE - Business Manager

A complete, offline-capable Progressive Web App (PWA) for managing store inventory, taking customer orders, and generating bilingual (English/Tamil) bills.

## Features
- **Clean UI:** Premium Light Theme layout with Emerald Green accents.
- **Inventory Management:** Add, edit, and safely delete items (warns on past order conflicts).
- **Order Generation:** Create orders, calculate totals, and append custom Transport/Auto Charges.
- **Bilingual Invoices:** Generates beautiful receipts with Tamil and English subtitles. 
- **PWA Ready:** Installable on any mobile device (Android/iOS) directly from the browser natively.
- **Offline Support:** Packaged with `manifest.json`, standard SVG icons, and a Service Worker (`sw.js`). Includes mobile-first touch support.

## Installation
Since this is a Progressive Web App (PWA):
1. Host these files on a standard web server (e.g. GitHub Pages or Vercel).
2. Visit the hosted URL in Safari (iOS) or Chrome (Android).
3. From the browser menu, select **Add to Home Screen**.
4. Launch the ANNAI STORE app directly from your mobile home screen.
