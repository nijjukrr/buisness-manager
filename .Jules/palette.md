## 2026-10-30 - Accessible Sidebar Navigation in Single-File PWA
**Learning:** In single-file HTML applications, replacing interactive `div` elements with native `<button>` tags and adding `:focus-visible` ring styles provides native keyboard tab accessibility and screen reader role identification without breaking layout or needing framework UI libraries.
**Action:** Always prefer native `<button>` elements for clickable controls and verify focus states using `:focus-visible`.
