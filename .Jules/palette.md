## 2026-11-11 - Modal Keyboard Accessibility and Action Button ARIA Labels in Vanilla PWA
**Learning:** In lightweight single-page PWAs lacking UI component libraries, custom modal overlays commonly lack basic keyboard dismissal (Escape key), backdrop click-to-dismiss, and accessibility roles (`role="dialog"`, `aria-modal="true"`, `aria-labelledby`). Furthermore, compact table actions like `✕`, `✓`, and `↺` render as cryptic unannounced symbols to assistive tech without `aria-label` and `title` attributes.
**Action:** When working on vanilla HTML/JS dashboards, bind a global `Escape` key and overlay click listener to dismiss active modals, and ensure all icon-only action buttons have explicit `aria-label` and `title` attributes for accessible tooltips and screen reader descriptions.
