## 2025-05-18 - Single-Page Vanilla Web App Accessible Modals and Icon Buttons
**Learning:** In lightweight static HTML/JS PWAs without UI frameworks, dialog overlays often lack standard keyboard dismissibility (Escape key) and outside-click dismissal, leaving keyboard and screen-reader users trapped or disoriented. Icon-only buttons (such as single Unicode glyphs like ✕, ✓, ↺) provide no semantic context to assistive tech without explicit `aria-label` and `title` attributes.
**Action:** When working on vanilla HTML/JS PWAs, always pair modal open/close functions with document-level Escape key listeners and overlay click-outside handlers, auto-focus the first element upon opening, and audit dynamic table templates to ensure all symbol/icon buttons have informative `aria-label` and `title` attributes.
