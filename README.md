# 🛒 ANNAI STORE - Business Manager

[![PWA Ready](https://img.shields.io/badge/PWA-Ready-10b981.svg?style=for-the-badge&logo=pwa)](https://web.dev/progressive-web-apps/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg?style=for-the-badge)](https://opensource.org/licenses/MIT)

**ANNAI STORE - Business Manager** is a premium, offline-capable Progressive Web App (PWA) designed for small retail businesses and grocery stores. It simplifies inventory management, order processing, and billing with a modern, high-performance interface.

![Dashboard Preview](https://img.shields.io/badge/Preview-Emerald_Green-10b981?style=flat-square)

## ✨ Key Features

- 📊 **Real-time Dashboard**: Monitor revenue, total orders, stock units, and customer counts at a glance.
- 📦 **Inventory Control**: Add, edit, and track stock levels with automated "Low Stock" and "Out of Stock" alerts.
- 📝 **Order Management**: Create customer orders, calculate subtotals, and include custom transport/auto charges.
- 🧾 **Bilingual Invoices**: Generate professional, print-ready receipts with both **English and Tamil** subtitles.
- 📈 **Business Analytics**: Gain insights into revenue trends and identify your top-selling products.
- 📶 **PWA & Offline Support**: Fully functional offline. Install it on Android or iOS directly from the browser.
- 🎨 **Premium UI**: Crafted with a sleek light theme using Emerald Green accents and modern typography (Syne & DM Sans).

## 🚀 Getting Started

### Prerequisites
All you need is a modern web browser (Chrome, Safari, or Edge).

### Installation (Local)
1. Clone the repository:
   ```bash
   git clone https://github.com/nijjukrr/buisness-manager.git
   ```
2. Open `index.html` in your browser, or serve it using a local server:
   ```bash
   npx serve .
   ```

### Installation (PWA)
1. Host the project on any static hosting service (GitHub Pages, Vercel, Netlify).
2. Visit the URL on your mobile device.
3. Select **"Add to Home Screen"** from your browser's menu.
4. Launch **ANNAI STORE** directly from your home screen.

## 🛠️ Technology Stack

- **Frontend**: HTML5, Vanilla JavaScript, CSS3
- **Fonts**: Google Fonts (Syne, DM Sans)
- **Icons**: SVG & Emoji-based icons
- **Storage**: LocalStorage for persistent data
- **PWA**: Service Workers (`sw.js`) and Web App Manifest (`manifest.json`)
